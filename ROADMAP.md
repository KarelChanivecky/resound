# Roadmap

## Signal processing

- **Configurable FFT and window parameters** — expose FFT size, window function, and window parameters as runtime configuration so different analysis strategies can be compared without code changes
- **Empirical optimisation of FFT parameters and z-score threshold** — systematic evaluation of how FFT size, window choice, and z-score coefficient affect detection accuracy across a range of instruments and recording conditions

## Application

- **Basic tuner UI** — visual display of the identified note and cent deviation
